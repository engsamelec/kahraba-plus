## القسم 2: النظام المرجعي — ماذا يتغيّر منه للساعات؟

تحليل صورة شجرة ملفات ADVANCED-MESSENGER-SERVICE (المرجع الذي بُنيت عليه الدراسات السابقة) يُظهر أن النظام مبني حول **الملابس الملونة**، لكن معظم مكوناته محايدة تجاه الفئة:

| المكوّن | ملابس | ساعات | التغيير المطلوب |
|---|---|---|---|
| `webhook_whatsapp.py` + التقاط `ctwa_clid` | ✓ | ✓ | لا شيء — محايد تماماً للفئة |
| `wa_logging.py` (ربط رسالة ← إعلان) | ✓ | ✓ | لا شيء |
| `adsTasks.py` (توليد إعلانات بالجملة) | منتج × لون × جمهور | منتج × (مينا × سوار) × جمهور | تعديل حلقة التوليد: محورا ضرب بدل محور واحد |
| `color_detector.py` / `color_image_selection.py` | لون القطعة | لون المينا **ولون السوار** | توسيع: اللون صار زوجاً (dial, band) لا قيمة واحدة |
| `order_management.py` | يسأل المقاس ويتحقق من توفره | لا سؤال مقاس (أو سؤال قطر 36/40 فقط) | تبسيط الفلو — محادثة أقصر |
| `pricing.py` / `price_validation.py` | ✓ | ✓ | لا شيء — حارس الأسعار يخدم الفئتين |
| `customer_context.py` / `db.py` / `redis_cache.py` / `GCS.py` | ✓ | ✓ | لا شيء |

**الاستنتاج الهندسي:** حوالي 80% من النظام مشترك بين الفئتين. الفرق يتركّز في نقطتين فقط: (1) نموذج بيانات الـ variant (محور لون واحد ← محورين)، و(2) فلو المحادثة (حذف/تبسيط سؤال المقاس). هذا وحده مؤشر قوي أن الفصل الكامل — نظامان منفصلان — هدر هندسي؛ الصواب فصلٌ منطقي داخل نظام واحد. (يُثبَّت هذا الاستنتاج أو يُعدَّل بأدلة البحث في الأقسام التالية.)

## القسم 8: تعديلات البوت والواتساب لفئة بلا مقاسات

من التفريغ السابق، أكبر نقاط الاحتكاك في محادثة الملابس هي سلسلة المقاس: «شو مقاسك؟» ← «خلص الـ L من الكحلي» ← تفاوض بديل ← مرتجعات مقاس. الساعات تلغي هذه السلسلة شبه كلياً:

**فلو محادثة الملابس (المرجع):**
1. رسالة واردة (مع referral الإعلان) ← رد مخصص باسم القطعة واللون الذي شاهدته الزبونة
2. سؤال اللون (إن لم يُحسم من الإعلان) ← إرسال صورة اللون الصحيح
3. **سؤال المقاس ← تحقق مخزون لكل (لون × مقاس)** ← بدائل عند النفاد
4. العنوان (دبوس ← عنوان) ← تأكيد ← حدث Purchase عبر CAPI

**فلو محادثة الساعات (المقترح):**
1. رسالة واردة ← رد مخصص بالموديل + تركيبة (المينا × السوار) التي جاءت من الإعلان
2. عرض التركيبات المتاحة (صور) إن طلبت الزبونة بديلاً — الاختيار بصري بحت
3. (اختياري) سؤال القطر 36/40 فقط إذا كان الموديل متوفراً بقطرين — سؤال واحد بإجابة من خيارين، لا جدول مقاسات
4. العنوان ← تأكيد ← حدث Purchase عبر CAPI — **نفس الخطوة حرفياً**

النتيجة العملية: محادثة أقصر بخطوة كاملة، إغلاق أسرع، ومصدر المرتجعات الأول في الملابس (المقاس) غير موجود. زاوية «هدية» تضيف فرعاً صغيراً للفلو (تغليف؟ توصيل لعنوان المُهدى إليه؟) يمكن تأجيله للمرحلة الثانية.
