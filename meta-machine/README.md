# ماكينة ميتا المؤتمتة — بلايز وقمصان نسائية (عرب الداخل)

نظام مؤتمت كامل يطبّق الدراسة `docs/clothing-meta-system-final-study.md` حرفياً:

```
[1] الكتالوج (catalog.py)
    products.json ← مصدر الحقيقة → feed CSV بمواصفات ميتا (variants صحيحة، صورة لكل لون)
         │
[2] مولّد الإعلانات (ads_builder.py)
    حملة CTWA واحدة · CBO $40/يوم · مجموعتان (Lookalike IL + عريض IL عربي)
    إعلان لكل (موديل × لون) بتسمية مفهرسة PROD_COLOR_AUD
         │  (النقرات تحمل ctwa_clid)
[3] المستقبِل (webhook.py)
    واتساب Cloud API webhook ← يلتقط ctwa_clid + source_ad_id من أول رسالة ← يخزنها
         │
[4] القياس (capi.py)
    عند تأكيد الطلبية → حدث Purchase عبر Conversions API
    action_source=business_messaging + ctwa_clid + منع تكرار (event_id)
         │
[5] العقل (rules.py — يعمل كل ساعة)
    يسحب الصرف لكل إعلان + يقاطعه مع الرسائل والمبيعات المستلمة من قاعدة البيانات
    → يوقف الخاسر تلقائياً · يرشّح الرابح للتغذية · تقرير يومي
```

## الإعداد

```bash
cd meta-machine
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # عبّي القيم — الأسرار برا الكود دائماً (درس credentials.json)
python db.py                # ينشئ قاعدة البيانات
python -m pytest tests/ -q  # اختبارات المسار الحرج
```

## التشغيل بالترتيب (لا تعكس الترتيب — الأتمتة تضاعف الموجود)

| الخطوة | الأمر | متى |
|---|---|---|
| 1. توليد الـ feed ورفعه للكتالوج | `python catalog.py` | مرة، ثم عند كل تغيير مخزون |
| 2. تشغيل مستقبِل الواتساب | `python webhook.py` | دائم (خلف https — ngrok أو سيرفر) |
| 3. تسجيل طلبية مؤكدة (يرسل CAPI تلقائياً) | `python order_cli.py <رقم> <قيمة>` | مع كل تأكيد |
| 4. بناء الحملة | `python ads_builder.py --dry-run` ثم بلا dry-run | بعد أسبوع أرقام يدوية |
| 5. قواعد القتل/التغذية | `python rules.py` (cron كل ساعة) | بعد إطلاق الحملة |

## قواعد مضمّنة من الدراسة (لا تعدّلها قبل ما تقرأ §4 و§10)

- ميزانية CBO: **$40/يوم** — تكفي مجموعتين بارتياح (140-187 رسالة/أسبوع متوقعة).
- قتل تلقائي: إعلان صرف ≥ 3× كلفة الرسالة المستهدفة بلا أي رسالة، أو ≥ 2× كلفة البيعة المستهدفة بلا بيعة.
- أول 14 يوماً: `rules.py` يعمل بوضع «تقرير فقط» تلقائياً — لا يوقف شيئاً (حماية مرحلة التعلم).
- زيادة الميزانية: يدوية فقط، ~20% كل 3-4 أيام بعد ثبوت الربحية (القرار قرارك، الماكينة بتقترح).
- فلتر العلامات: أي منتج فيه `brand_flag: protected` بالـ products.json لا يدخل الإعلانات أبداً.
- حارس الأسعار: أي سعر خارج مدى المنتج المسجل لا يُرسل للزبون (درس price_validation).
